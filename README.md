# Binary-Search-Tree

## Description

This project implements a balanced Binary Search Tree (BST) in JavaScript. It includes methods for inserting, deleting, and searching for values, as well as for traversing the tree using level-order, in-order, pre-order, and post-order depth-first strategies. The tree automatically maintains balance through height and depth calculations, and can be rebalanced when necessary. This implementation demonstrates how BSTs provide efficient, logarithmic-time operations for sorted data storage and retrieval, and how maintaining balance ensures optimal performance for large data sets.

### Prerequisites

- Node.js installed on your machine. Check it with the following command.

```bash
node -v
```

- You may need a package.json 

```bash
npm init -y
```
- Add the following line:

```bash
"type": "module"
```

## Setup and Installation

1. Clone the repository
2. Open a terminal in the project directory and run the following command:

```bash
node drive.js
```
